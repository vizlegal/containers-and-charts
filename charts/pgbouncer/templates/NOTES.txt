PgBouncer is deployed as {{ include "pgbouncer.fullname" . }} in namespace {{ .Release.Namespace }}.

Connect from inside the cluster:

  host: {{ include "pgbouncer.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local
  port: {{ .Values.service.port }}

Connect from your machine:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "pgbouncer.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}
  psql -h 127.0.0.1 -p {{ .Values.service.port }} -U <user> <database>

Inspect pool state (requires a user listed in admin_users or stats_users):

  psql -h 127.0.0.1 -p {{ .Values.service.port }} -U <admin_user> pgbouncer -c 'SHOW POOLS;'
